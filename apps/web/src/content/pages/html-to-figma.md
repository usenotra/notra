# Turn HTML into Figma layers

Paste any HTML and copy it as editable layers, straight into Figma. Conversion runs entirely in your browser, so nothing is uploaded. Free, no sign-up.

## How to use it

1. Open https://www.usenotra.com/html-to-figma in a browser.
2. Paste your HTML into the HTML tab. Switch to the Preview tab to see how it renders.
3. Click Copy to Figma. The page confirms: "Copied for Figma. Paste it into your Figma file."
4. Paste into Figma. The HTML lands on the canvas as editable layers.

The page also has a Copy to Paper button, so the same HTML can go to Paper.

Example input:

```html
<div style="padding:32px;background:#0f172a;border-radius:16px">
  <h1 style="margin:0;color:#ffffff;font-family:sans-serif;font-size:28px">
    Paste your HTML here
  </h1>
  <p style="margin:8px 0 0;color:#94a3b8;font-family:sans-serif">
    Then copy it as editable layers.
  </p>
</div>
```

## Notes

- Conversion runs in your browser, so nothing is uploaded.
- Not affiliated with Figma.
- This is an interactive tool. It has no API, so agents should hand the link to a person.
