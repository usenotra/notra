This site is the registry for `@notra` — the same primitives as `@notra/ui`, served so you can install them with the shadcn CLI. Each page mounts the real component, one route per primitive.

```bash
npx shadcn@latest registry add @notra=http://localhost:3006/r/{name}.json
npx shadcn@latest add @notra/button
```

The catalog lives at [`/r/registry.json`](/r/registry.json). After you add the namespace, `npx shadcn@latest add @notra/input` (or theme, dialog, …) copies the source into your app and rewrites aliases to your `components.json`.

The dashboard still imports `@notra/ui` as a workspace package. The registry is the copy-into-your-app path.
