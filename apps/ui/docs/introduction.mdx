**Notra UI** is the showcase for `@notra/ui`, the component package behind the Notra dashboard. Components shown here are built with the same tokens and styles, as site examples you can copy into your app.

Every component and block is published to the official shadcn registry directory under `@notra`, so you can install them by name.
