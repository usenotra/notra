# Introduction

**Notra UI** is the showcase for `@notra/ui`, the component package behind the Notra dashboard. Every page here renders the real styles, so what you see is what ships.

Run it locally with `bun run dev --filter=ui` and open [localhost:3006](http://localhost:3006).
