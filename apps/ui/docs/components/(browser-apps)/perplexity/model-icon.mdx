<Component path="perplexity/examples/perplexity-model-icon" />

```bash
bunx shadcn@latest add @notra/perplexity-model-icon
```

`provider` is one of `perplexity`, `openai`, `google`, `anthropic`, `kimi`, `zhipu`, `xai` or `nvidia`. Logos render at 16px in grayscale, like Perplexity's menu. The inline SVGs live in `perplexity-icons.tsx`.
