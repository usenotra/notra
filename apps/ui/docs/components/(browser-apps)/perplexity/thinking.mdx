<Component path="perplexity/examples/perplexity-thinking" />

```bash
bunx shadcn@latest add @notra/perplexity-thinking
```

The label shimmers with the Notra [Shimmer](/components/shimmer), which the CLI installs with it. It fades in and is announced politely to screen readers. Set `reducedMotion` to show plain text. `label` defaults to `Thinking...`.
