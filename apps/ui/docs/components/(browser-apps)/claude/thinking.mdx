<Component path="claude/examples/claude-thinking" />

```bash
bunx shadcn@latest add @notra/claude-thinking
```

`ClaudeThinking` pairs an animated [Spinner](/components/claude/spinner) with a serif verb that runs through [Shimmer](/components/shimmer) and changes every 2.2 seconds. It is a polite live region. Reduced motion stops the spinner and keeps the first verb.

| Prop | Default | Description |
| --- | --- | --- |
| `verbs` | `Untangling`, `Pondering`, ... | The verbs to cycle through. |
| `intervalMs` | `2200` | Time per verb. |
| `reducedMotion` | system setting | Forces reduced motion on or off. |
