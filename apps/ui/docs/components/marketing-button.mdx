```bash
bunx shadcn@latest add https://ui.usenotra.com/r/marketing-button.json
```

`MarketingButton` wraps the shadcn `Button`, which is built on Base UI's `Button`, so it takes every Button prop. The gradients and hover states ship as two Tailwind utilities, `marketing-gradient-primary` and `marketing-gradient-light`, added to your CSS by the install.

| Prop | Default | Description |
| --- | --- | --- |
| `variant` | `primary` | `primary` is the purple gradient, `light` is the white one. |
| `size` | `default` | `default` is 44px tall, `lg` is 48px. |
| `render` | none | Base UI's `render` prop. Pass an element to render a link. |
| `nativeButton` | `true` | Set to `false` when `render` is not a `<button>`. |
