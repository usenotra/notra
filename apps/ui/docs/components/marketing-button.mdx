`MarketingButton` is built on Base UI's `Button`, like the shadcn `Button`, so it takes every Button prop, including a `className` callback. The gradients and hover states ship as two Tailwind utilities, `marketing-gradient-primary` and `marketing-gradient-light`, added to your CSS by the install.

| Prop | Default | Description |
| --- | --- | --- |
| `variant` | `primary` | `primary` is the purple gradient, `light` is the white one. |
| `size` | `default` | `default` is 44px tall, `lg` is 48px. |
| `render` | none | Base UI's `render` prop. Pass an element to render a link. |
| `nativeButton` | `true` | Set to `false` when `render` is not a `<button>`. |
