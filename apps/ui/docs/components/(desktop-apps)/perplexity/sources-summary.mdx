A static label, like Perplexity's: the favicons of the first three distinct domains overlap in front of the count, like `16 sources`. It isn't clickable. Nothing renders when `sources` is empty.

| Prop | Default | Description |
| --- | --- | --- |
| `sources` | | The sources of the answer. |
