<Component path="chatgpt/examples/chatgpt-thread" />

```bash
bunx shadcn@latest add https://ui.usenotra.com/r/chatgpt-thread.json
```

`ChatgptThread` paints ChatGPT's background and font, centers its children in a 48rem column with 2.5rem between turns, and pins `footer` below a shadcn `ScrollArea`. It follows new content while you're at the bottom and shows a scroll-to-bottom button once you scroll up.

| Prop | Default | Description |
| --- | --- | --- |
| `footer` | | Rendered under the scroll area, usually a `ChatgptComposer`. |
| `autoScroll` | `true` | Keeps the view pinned to the latest message as content grows. |

Give it a height, like `h-96` or `flex-1` inside a sized parent, so the messages scroll.
