<Component path="chatgpt/examples/chatgpt-message" />

```bash
bunx shadcn@latest add @notra/chatgpt-message
```

With `from="user"` the text sits in ChatGPT's gray-blue pill, capped at 70% width and aligned to the end. Assistant turns have no bubble. `reasoning` renders above the reply and `actions` below it, hidden until you hover or focus the message on devices that can hover.

| Prop | Default | Description |
| --- | --- | --- |
| `from` | | `"user"` or `"assistant"`. |
| `reasoning` | | Assistant only. Usually a `ChatgptReasoning`. |
| `actions` | | Assistant only. Usually `ChatgptActions`. |
