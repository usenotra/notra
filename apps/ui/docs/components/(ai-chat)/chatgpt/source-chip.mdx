---
title: Source Chip
description: An inline citation pill that opens a hover card with the cited sources.
---

<Component path="chatgpt/examples/chatgpt-source-chip" />

```bash
bunx shadcn@latest add @notra/chatgpt-source-chip
```

`ChatgptSourceChip` shows the first publisher with a `+N` for the rest, set inline at the end of a claim. Hovering it opens a shadcn `HoverCard` that lists up to three sources, each with a favicon, publisher, title and a two-line snippet. The chip links to the first source's `href` when it has one.

| Prop | Default | Description |
| --- | --- | --- |
| `sources` | | The cited `ChatgptActivitySource`s. Nothing renders when it is empty. |
