<Component path="gemini/examples/gemini-actions" />

```bash
bunx shadcn@latest add @notra/gemini-actions
```

`GeminiActions` renders Gemini's row of round icon buttons, thumbs up and thumbs down. Each one is a shadcn `Button` with a shadcn `Tooltip` below it.

| Prop | Default | Description |
| --- | --- | --- |
| `onGoodResponse` | | Called when the thumbs up is clicked. |
| `onBadResponse` | | Called when the thumbs down is clicked. |

Build your own row from `GeminiActionButton`, which takes a `label` for its tooltip and `aria-label`. Wrap the row in a shadcn `TooltipProvider`:

```tsx
<TooltipProvider delay={200}>
  <GeminiActionButton label="Regenerate" onClick={regenerate}>
    <RefreshCwIcon />
  </GeminiActionButton>
</TooltipProvider>
```
