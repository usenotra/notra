<Component path="gemini/examples/gemini-source-chip" />

```bash
bunx shadcn@latest add @notra/gemini-source-chip
```

`GeminiSourceChip` is a small rounded pill with the source name, set inline in the answer. It links to `href` in a new tab. Hovering it opens a shadcn `HoverCard` with the favicon and name, the title and a two-line description. Favicons come from Google's favicon service unless the source sets `favicon`.

You rarely place chips by hand: `GeminiStoryText` turns `{{id}}` markers in the text into chips for the `sources` you pass.

| Prop | Default | Description |
| --- | --- | --- |
| `source` | | `{ id, name, title, domain, href?, description?, favicon? }`. |
