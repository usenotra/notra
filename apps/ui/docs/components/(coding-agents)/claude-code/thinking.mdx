<Component path="claude-code/examples/claude-code-thinking" />

```bash
bunx shadcn@latest add @notra/claude-code-thinking
```

A shadcn `Collapsible`, closed by default. The trigger is a dim italic `∴` line with a `(click to expand)` hint. Open, it shows the thought text in italics, indented under the line. It takes every `Collapsible` prop, like `defaultOpen` and `onOpenChange`.

| Prop | Default | Description |
| --- | --- | --- |
| `label` | `Thinking…` | The line next to the `∴`, like `Thought for 3s`. |
| `children` | | The thought text shown when open. |
