<Component path="claude-code/examples/claude-code-tool-call" />

```bash
bunx shadcn@latest add @notra/claude-code-tool-call
```

`ClaudeCodeToolCall` prints `⏺ tool(arg)` and starts collapsed. Opening it shows the result on a `⎿` line and any children below it. The dot is green for `success`, amber for `pending` and red for `error`.

The root is a shadcn `Collapsible` and the `⏺` line is its trigger, rendered as a shadcn `Button` with a `▸` / `▾` marker. It takes `open`, `defaultOpen` and `onOpenChange`.

| Prop | Default | Description |
| --- | --- | --- |
| `tool` | | Tool name, like `Bash`, `Read` or, for an MCP tool, `notra - list_events (MCP)`. |
| `arg` | | Argument shown in parentheses: a command or path, or `key: "value"` pairs for MCP tools. |
| `result` | | The result line. |
| `status` | `success` | `success`, `pending` or `error`. |
| `defaultOpen` | `false` | Starts expanded. |
| `children` | | Extra output under the result, shown with preserved whitespace. |
