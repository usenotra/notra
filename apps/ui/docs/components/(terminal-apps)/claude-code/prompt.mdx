```bash
bunx shadcn@latest add @notra/claude-code-prompt
```

`ClaudeCodePrompt` is a shadcn `InputGroup` with the `❯` as an `InputGroupAddon` and an `InputGroupInput`, between two shadcn `Separator` rules. The effort level sits above and the permission mode below, with key hints in shadcn `Kbd`. At `ultracode` effort the rules turn into Claude Code's rainbow. The example cycles modes on Shift+Tab, like Claude Code, and picks mode and effort with a shadcn `ToggleGroup`.

| Prop | Default | Description |
| --- | --- | --- |
| `mode` | `auto` | `auto`, `manual`, `accept-edits`, `plan` or `bypass`. |
| `effort` | `xhigh` | `low`, `medium`, `high`, `xhigh`, `max`, `ultracode`, or `false` to hide the line. |
| `pullRequest` | | `{ number, href? }`. Shows `· PR #123` as an underlined link after the mode, like Claude Code does for the branch's pull request. |
| `value`, `defaultValue`, `onChange` | | Input state, controlled or uncontrolled. |
| `onKeyDown`, `placeholder` | | Passed to the input. |
| `inputRef`, `inputClassName` | | Ref and classes for the input. |

The other props go to the root `div`. `CLAUDE_CODE_MODE_ORDER` and `CLAUDE_CODE_EFFORT_ORDER` list the modes and efforts in Claude Code's order.
