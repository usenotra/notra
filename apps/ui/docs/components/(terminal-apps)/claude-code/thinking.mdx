<Component path="claude-code/examples/claude-code-thinking" />

```bash
bunx shadcn@latest add @notra/claude-code-thinking
```

A shadcn `Collapsible`, closed by default. The trigger is a ghost `Button` styled as a dim italic line, with the `ctrl+o` hint in a shadcn `Kbd`. Open, it shows the thought text, indented. It takes every `Collapsible` prop.

| Prop | Default | Description |
| --- | --- | --- |
| `label` | `Thinking…` | The line next to the `∴`. |
| `children` | | The thought text shown when open. |
