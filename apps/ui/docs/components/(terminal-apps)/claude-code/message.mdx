```bash
bunx shadcn@latest add https://ui.usenotra.com/r/claude-code-message.json
```

`ClaudeCodeMessage` renders a user turn behind a `❯` on Claude Code's darker bar when `from="user"`. The default, `from="assistant"`, is plain monospace text. Add padding and rounding to the user bar with `className`, like `rounded-sm px-2.5 py-1.5`.
