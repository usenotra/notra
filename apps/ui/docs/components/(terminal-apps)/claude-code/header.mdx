```bash
bunx shadcn@latest add @notra/claude-code-header
```

`ClaudeCodeHeader` is the banner Claude Code prints on start. The `compact` variant is the short one Claude Code shows in narrow terminals: the logo next to the title, model and working directory. The `full` variant is the bordered banner. The left column greets the user above the pixel logo, model, organization and working directory. The right column lists tips and release notes. The columns stack on small screens. The banner is a shadcn `Card` with its label as the `CardTitle`, and the dividers are shadcn `Separator`s.

| Prop | Default | Description |
| --- | --- | --- |
| `variant` | `full` | `full` for the bordered banner, `compact` for the logo with three lines next to it. |
| `title` | `Claude Code` | The label cut into the top border. |
| `version` | `v2.1.206` | Shown next to the title. |
| `user` | | Name in the "Welcome back" greeting. |
| `model`, `org`, `cwd` | | Lines under the logo. Empty ones are skipped. |
| `tips` | | Lines under "Tips for getting started". Pass `[]` to hide the section. |
| `whatsNew` | | Lines under "What's new". Pass `[]` to hide the section. |

`ClaudeCodeLogo` is the pixel logo on its own. It fills with `currentColor`, and `scale` sets its size in pixels per cell. It defaults to `4`.
