<Component path="opencode/examples/opencode-window" />

```bash
bunx shadcn@latest add https://ui.usenotra.com/r/opencode-window.json
```

`OpencodeWindow` is a shadcn `Card`, rounded and bordered, that paints the TUI background and sets the monospace font. It has no padding, so the full session can split into a main column and a sidebar. It accepts every `Card` prop.
