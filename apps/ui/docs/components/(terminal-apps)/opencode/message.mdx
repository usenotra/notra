<Component path="opencode/examples/opencode-message" />

```bash
bunx shadcn@latest add @notra/opencode-message
```

`from="user"` renders the turn in a panel with OpenCode's purple rule. Assistant turns, the default, are plain text with two optional slots.

| Prop | Default | Description |
| --- | --- | --- |
| `from` | `assistant` | `user` or `assistant`. |
| `search` | | Rendered above an assistant reply, usually `OpencodeSources`. |
| `actions` | | Rendered below an assistant reply. |
