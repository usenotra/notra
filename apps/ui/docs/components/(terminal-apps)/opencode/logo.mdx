<Component path="opencode/examples/opencode-logo" />

```bash
bunx shadcn@latest add https://ui.usenotra.com/r/opencode-logo.json
```

`OpencodeLogo` is an `svg` drawn on a 234 by 42 grid. Its three fills come from the `--opencode-logo-*` tokens, so it switches with light and dark mode.

| Prop | Default | Description |
| --- | --- | --- |
| `scale` | `1` | Multiplies the 234 by 42 size. |
| `aria-label` | `OpenCode` | The accessible name. |
