<Component path="codex/examples/codex-composer" />

```bash
bunx shadcn@latest add @notra/codex-composer
```

`CodexComposer` is a shadcn `InputGroup` with the `›` marker in an `InputGroupAddon`, under a shadcn `Separator`. It passes every other prop to the `InputGroupInput`, so use `value` and `onChange` for a controlled prompt or `defaultValue` for an uncontrolled one. `className` styles the wrapper and `inputClassName` the input.

| Prop | Default | Description |
| --- | --- | --- |
| `placeholder` | `Ask Codex to do anything` | The input placeholder. |
| `context` | `88% context left` | Shown on the right of the footer, after `? for shortcuts`. |
