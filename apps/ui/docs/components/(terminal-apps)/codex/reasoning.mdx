```bash
bunx shadcn@latest add @notra/codex-reasoning
```

`CodexReasoning` is a dim bullet and a bold italic summary line, the way Codex surfaces a reasoning step between tool calls. It renders a `div` and takes all of its props.

| Prop | Default | Description |
| --- | --- | --- |
| `children` | | The reasoning summary. |
