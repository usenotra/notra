<Component path="codex/examples/codex-terminal" />

```bash
bunx shadcn@latest add https://ui.usenotra.com/r/codex-terminal.json
```

`CodexTerminal` is a shadcn `Card`. The title bar is a `CardHeader` with a `CardTitle`, and children go in a `CardContent` with Codex's spacing. It accepts every `Card` prop.

| Prop | Default | Description |
| --- | --- | --- |
| `title` | | Text in the title bar next to the three window dots, like `codex — ~/acme/web`. |
