A rebuild of a session in OpenAI's Codex CLI, composed from the [Codex components](/components/codex/terminal). It has the banner and greeting, a banded user turn, a `Ran` cell with shell colors and folded output, an `Explored` group and a markdown answer with a list and a table. The composer is pinned under the transcript.

<Component path="codex/examples/codex-demo" />

## Installation

```bash
bunx shadcn@latest add @notra/codex
```

This adds every Codex component to `components/codex` along with the demo session.

The components use the system monospace stack through `font-codex`. Point it at your own mono font to change it.

## CodexTerminal

The root is a shadcn `Card` with the window chrome, so it takes every `Card` prop. `title` sets the text in the title bar and `footer` pins content under the scrolling transcript. Put `CodexHeader`, `CodexMessage`, `CodexExec`, `CodexExplored` and `CodexWorking` inside it in transcript order and pass `CodexComposer` as the `footer`.

## Theming

The block is built on the shadcn Base UI style. It uses shadcn `Button`, `Card`, `Collapsible`, `InputGroup`, `Kbd` and `ScrollArea`, and the CLI installs any you're missing.

Its colors are `--codex-*` tokens that the CLI adds to your CSS, mapped to utilities like `bg-codex-bg` and `text-codex-blue`. Codex is a terminal, so the light and dark values are the same dark palette. Change them in your CSS to retheme it, or point them at your own tokens:

```css
:root {
  --codex-bg: var(--card);
  --codex-blue: var(--primary);
}
```
