A rebuild of the Claude Code terminal UI, composed from the [Claude Code components](/components/claude-code/terminal). One finished turn folds its shell call into `Ran 1 shell command`, answers and closes with a `✻ Cogitated for 7s` line. The next turn is still running, with its todos, a pending tool call and the orange spinner. Click `Ran 1 shell command` to see the call, and focus the prompt and press Shift+Tab to cycle the permission mode.

## Installation

```bash
bunx shadcn@latest add @notra/claude-code
```

This adds every Claude Code component to `components/claude-code` and a demo session.

The components use your system's monospace stack. Point `--font-claude-code` at your own mono font, like Geist Mono, to change it.

## ClaudeCodeTerminal

The root is a shadcn `Card` with a title bar and a stacked body. Put the other parts inside in the order Claude Code prints them: `ClaudeCodeHeader`, then per turn a user `ClaudeCodeMessage`, tool calls, the answer and a `ClaudeCodeTurnSummary`, and `ClaudeCodePrompt` last.

| Prop | Default | Description |
| --- | --- | --- |
| `title` | | Text in the title bar. |
| `contentClassName` | | Classes for the body. |

## Theming

The block is built on the shadcn Base UI style. It uses shadcn `Card`, `Collapsible`, `InputGroup` and `ScrollArea`, and the CLI installs any you're missing.

Its colors are `--claude-code-*` tokens that the CLI adds to your CSS, mapped to utilities like `bg-claude-code-bg` and `text-claude-code-accent`. The terminal stays dark in both light and dark mode. Change the tokens in your CSS to retheme it:

```css
:root {
  --claude-code-bg: #0d1117;
  --claude-code-accent: var(--primary);
}
```
