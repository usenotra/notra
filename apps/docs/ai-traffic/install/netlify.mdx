This guide adds the Notra tracker to a Netlify Edge Functions app. It takes about five minutes and one file: `netlify/edge-functions/geo.ts`.

<Tip>
  The Traffic page has a **Copy agent prompt** button. Paste it into Claude Code, Cursor or Codex and the agent will do these steps for you.
</Tip>

<Steps>
  <Step title="Get your token">
    Open **Traffic** in the GEO sidebar. Until the first event arrives the page shows **No activity yet** with the full install panel: **Install the package**, **Set your token** and **Add the proxy**. The **Set your token** section shows the token. The panel also has a **Copy agent prompt** button that copies an instruction block you can paste into a coding agent.

    <Visibility for="agents">

    From the API, reading the snippets needs `traffic.read` and issuing the token needs `traffic.write`:

    ```bash
    curl https://api.usenotra.com/v1/geo/ingest/setup \
      -H "Authorization: Bearer $NOTRA_API_KEY"
    ```

    ```bash
    curl -X POST "https://api.usenotra.com/v1/geo/ingest/token?projectId=$PROJECT_ID" \
      -H "Authorization: Bearer $NOTRA_API_KEY"
    ```

    Both return `ingestUrl`, `snippet` (the Next.js snippet) and `snippets` with `next`, `nuxt`, `tanstack`, `astro`, `sveltekit` and `netlify` keys. The token endpoint adds `token`. The ingest routes are organization-level. Pass `projectId` to bind the token to one project, or omit it to track the whole organization. Issuing a token does not invalidate tokens issued earlier.

    </Visibility>

    Install the same project token on every domain the project tracks. Add extra hostnames under **Tracked domains** in GEO settings.
  </Step>
  <Step title="Install the package">
    <CodeGroup>
    ```bash npm
    npm install @usenotra/geo
    ```

    ```bash yarn
    yarn add @usenotra/geo
    ```

    ```bash pnpm
    pnpm add @usenotra/geo
    ```

    ```bash bun
    bun add @usenotra/geo
    ```
    </CodeGroup>

    The package has zero dependencies and no Node APIs in the core, so it runs on edge runtimes.
  </Step>
  <Step title="Set the environment variable">
    Add the token as `NOTRA_GEO_TOKEN` in your site's environment variables, locally and at your hosting provider. Never hardcode or commit it.
  </Step>
  <Step title="Add the tracker">
    ```typescript netlify/edge-functions/geo.ts
    import { createGeoHandler } from "@usenotra/geo/netlify";
    import type { Context } from "@netlify/edge-functions";

    const geo = createGeoHandler({
      token: Deno.env.get("NOTRA_GEO_TOKEN")!,
      endpoint: "https://ingest.usenotra.com",
    });

    export default (request: Request, context: Context) => {
      geo(request, context);
    };

    export const config = { path: "/*" };
    ```
  </Step>
  <Step title="Deploy and verify">
    Deploy your site. The Traffic page switches from the install panel to the dashboard as soon as the first AI crawler or referral is stored. Crawlers visit on their own schedule, so the first event can take a while on a quiet site.
  </Step>
</Steps>
