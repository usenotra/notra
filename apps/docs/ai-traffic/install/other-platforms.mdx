The tracker has native integrations for Next.js, TanStack Start, Nuxt, Astro, SvelteKit and Netlify Edge Functions. The core has no Node APIs and no dependencies, so it can run in most edge or server runtimes.

<Warning>
  This page is a placeholder. The outline below is what it will cover.
</Warning>

- Express and Hono middleware.
- Cloudflare Workers.
- Vercel log drains and Cloudflare Logpush (server logs instead of middleware).
- Static sites with no server runtime.
