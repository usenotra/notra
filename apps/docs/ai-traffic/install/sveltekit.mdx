This guide adds the Notra tracker to a SvelteKit app in about five minutes, and you only touch one file, `src/hooks.server.ts`.

<Tip>
  The Traffic page has a **Copy agent prompt** button. Paste the prompt into Claude Code, Cursor or Codex and the agent runs these steps for you.
</Tip>

<Steps>
  <Step title="Get your token">
    Open **Traffic** in the GEO sidebar. Until the first event arrives the page shows **No activity yet** with the full install panel: **Install the package**, **Set your token** and **Add the proxy**. The token appears in the **Set your token** section, and the **Copy agent prompt** button copies an instruction block you can paste into a coding agent.

    <Visibility for="agents">

    From the API, reading the snippets needs `traffic.read` and issuing the token needs `traffic.write`:

    ```bash
    curl https://api.usenotra.com/v1/geo/ingest/setup \
      -H "Authorization: Bearer $NOTRA_API_KEY"
    ```

    ```bash
    curl -X POST "https://api.usenotra.com/v1/geo/ingest/token?projectId=$PROJECT_ID" \
      -H "Authorization: Bearer $NOTRA_API_KEY"
    ```

    Both return `ingestUrl`, `snippet` (the Next.js snippet) and `snippets` with `next`, `nuxt`, `tanstack`, `astro`, `sveltekit` and `netlify` keys. The token endpoint also returns `token`. The ingest routes are organization-level, so pass `projectId` to bind the token to one project or omit it to track the whole organization. Issuing a token doesn't invalidate tokens issued earlier.

    </Visibility>

    Install the same project token on every domain the project tracks, and add extra hostnames under **Tracked domains** in GEO settings.
  </Step>
  <Step title="Install the package">
    <CodeGroup>
    ```bash npm
    npm install @usenotra/geo
    ```

    ```bash yarn
    yarn add @usenotra/geo
    ```

    ```bash pnpm
    pnpm add @usenotra/geo
    ```

    ```bash bun
    bun add @usenotra/geo
    ```
    </CodeGroup>

    The package has zero dependencies and no Node APIs in the core, so it runs on edge runtimes. You can also install it with npm, pnpm or yarn.
  </Step>
  <Step title="Set the environment variable">
    Add the token as `NOTRA_GEO_TOKEN` in your site's environment variables, both locally and at your hosting provider, and never hardcode or commit it.
  </Step>
  <Step title="Add the tracker">
    ```typescript src/hooks.server.ts
    import { env } from "$env/dynamic/private";
    import { createGeoHandle } from "@usenotra/geo/sveltekit";

    export const handle = createGeoHandle({
      token: env.NOTRA_GEO_TOKEN!,
      endpoint: "https://ingest.usenotra.com",
    });
    ```

    The handle captures requests alongside `resolve` and waits for the send before returning. If `src/hooks.server.ts` already has a `handle`, compose with `sequence` from `@sveltejs/kit/hooks`.
  </Step>
  <Step title="Deploy and verify">
    After you deploy your site, the Traffic page switches from the install panel to the dashboard once Notra stores the first AI crawler visit or referral. Crawlers visit on their own schedule, so the first event can take a while on a quiet site.
  </Step>
</Steps>
