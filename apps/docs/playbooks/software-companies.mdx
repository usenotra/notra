More software buyers now start with "what's the best tool for..." in ChatGPT, Claude or Perplexity. The answer is usually a short list. In an [Ahrefs study of 26,283 cited URLs](https://ahrefs.com/blog/best-lists-research/), "best X" listicles were 43.8% of the page types AI engines cited for software, and brands ranked higher on those lists were mentioned more.

## Set up

- **Prompts.** Cover three intents. Problem ("how do i automate release notes"), category ("best changelog tools for startups") and comparison ("globex alternatives"). Add a buyer detail such as team size or stack.
- **Competitors.** Add direct competitors and the indirect ones buyers consider, like spreadsheets or an in-house build. Mark them **Indirect**.
- **Personas.** Generate [personas](/geo/personas) for each buying role, for example the engineering lead and the founder. Compare where each one hears about you.
- **Search Console.** Connect it so prompt suggestions come from the queries you already rank for.

## What to work on

| Lever | Why it matters for software | Where in Notra |
| --- | --- | --- |
| Comparison and alternatives pages | Engines quote them directly for "X vs Y" and "alternatives to X" prompts | [GEO writer](/geo/writer), comparison format |
| "Best X" listicles | The page type AI engines cite most for software recommendations | [Shelf space](/geo/shelf-space) |
| Docs and pricing pages | Assistants fetch them live to check features and price | [AI traffic](/ai-traffic/overview), **Cited in answer** |
| Changelog | Keeps pages fresh. AI engines favor recently updated content ([Ahrefs](https://ahrefs.com/blog/do-ai-assistants-prefer-to-cite-fresh-content/)) | [Changelogs](/content/changelogs) |

## Metrics to watch

- [Share of voice](/geo/metrics/share-of-voice) on category prompts.
- [Position](/geo/metrics/position) on comparison prompts. Being first matters more than being listed.
- AI referrals reaching `/signup` or `/pricing`. Add them as **Conversion paths**.
