Pick languages under **Settings > Languages**. English is on by default. A project can scan up to four of about 30 supported languages.

- Notra translates your prompts into each language before the scan, so you maintain one prompt list.
- Each language multiplies the answers a scan uses.
- [Conversations](/geo/conversations) and [brand sentiment](/geo/metrics/sentiment) only use English answers.
- **Performance by language** on the GEO **Overview** page and `GET /geo/visibility/language-share` report mention rate per language.
