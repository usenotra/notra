A zero mention rate means either missing data or a real zero. Check these causes in order.

<AccordionGroup>
  <Accordion title="No scan has finished yet">
    Results appear once the first scan completes, usually within minutes of onboarding. To check, look at the Overview page. It shows a running scan and polls until it finishes. Press **Run Scan** (`R`) if nothing has run.
  </Accordion>
  <Accordion title="Engines name you differently">
    The judge only counts your company name and [aliases](/geo/brand-and-domains). If engines call you by a product name or your domain, add it. To check, open a few answers on the Prompts page and search for how you are named.
  </Accordion>
  <Accordion title="Zero on some engines only">
    Each engine has its own index and training data. Engines labelled **No web search** only know what the model learned in training, so they miss newer brands and pages. To check, see the **Mention rate by engine** table on the GEO **Overview** page.
  </Accordion>
  <Accordion title="Your prompts are too broad">
    "best software" will never name a niche product. To check, compare them with the prompts where competitors show up, then follow [Writing good prompts](/geo/prompts#writing-good-prompts).
  </Accordion>
  <Accordion title="It is a real zero">
    Engines do not recommend you for these questions yet. Start with [Content gaps](/geo/content-gaps) and [Shelf space](/geo/shelf-space).
  </Accordion>
</AccordionGroup>
