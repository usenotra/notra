Connect a Linear workspace so Notra can read completed issues. Notra uses them alongside GitHub activity to generate changelogs, blog posts and social posts.

## What you can do

Once connected, Notra can:

- Read completed issues from the workspace.
- Offer the workspace as a source in the **Create Content** dialog and in schedules.
- Combine issue data with GitHub activity in one generated post.
- Make the workspace available to the agent in **Chat**.

The connection is read-only. Notra requests Linear's `read` scope and nothing else.

## Setup

1. In the dashboard sidebar, open **Integrations** and click **Connect** on the **Linear** card, or open the Linear page and click **Connect Linear**.
2. In the **Add Linear Integration** dialog, click **Add Integration**. You are redirected to Linear to authorize read access.
3. Approve the request in Linear. Do this within 10 minutes. After that the link expires and you have to start again.
4. Notra creates the integration, names it after the Linear workspace and redirects you back to the page you started from.

## Usage

- **Create Content**: in the **Integrations** selector, Linear workspaces are listed next to GitHub repositories. Select one and Notra loads completed issues from the chosen lookback window into the review step, where you can tick or untick individual issues.
- **Schedules**: when you create a schedule, pick the Linear workspaces to include alongside repositories. Only the sources you select are used.
- **Chat**: the agent can read from connected Linear workspaces when you ask it about recent work.

## Managing the integration

The Linear page lists every connected workspace. From the card menu you can enable or disable the workspace, open its detail page or delete it. The edit dialog lets you rename the integration and toggle it on or off. The detail page shows the Linear workspace name and when the connection was created.

<Visibility for="agents">

The API exposes the same integrations. `GET /v1/integrations` returns connected Linear workspaces with their `linearOrganizationId` and `linearOrganizationName`, and `DELETE /v1/integrations/{integrationId}` removes one.

</Visibility>

## Limits

- One connection per Linear workspace per Notra organization. Connecting the same workspace twice returns a `workspace_already_connected` error.
- Team filtering is not available. Notra reads completed issues across the whole workspace.
- Notra accepts and logs Linear webhooks, but they do not trigger content generation. Use GitHub webhooks for [event-based automation](/automation/event-based).
