This guide shows how to connect Notra to [Framer](https://www.framer.com/) and pull your posts into a Framer site with the official Notra plugin. Framer is listed under **Output** on the Integrations page; its card opens the same four-step setup guide described here.

## Prerequisites

- Access to a Framer project.
- A Notra API key with read access to posts (`posts.read`).
- Posts in Notra that you want to import.

## Install

### Framer Marketplace

Install the official Notra plugin from the [Framer Marketplace](https://www.framer.com/marketplace/plugins/notra/).

### Inside Framer

1. Open your Framer project.
2. Open **Assets** > **Plugins**.
3. Search for `Notra`.
4. Click **Install**.

## Connect Notra to Framer

1. In the Notra dashboard sidebar, open **API Keys**.
2. Create a new key with read-only access to posts.

<img
  src="/images/api/api-keys-light.webp"

  className="block dark:hidden"
/>
<img

  alt="API Keys page, create a read-only key for Framer"
  className="hidden dark:block"

3. Open the Notra plugin in Framer.
4. Paste your API key when prompted.
5. Browse your posts in the plugin and choose which ones to pull into your Framer site.

<Note>
  The plugin only reads from Notra. A key with `posts.read` is enough; it cannot change anything in your workspace.
</Note>
