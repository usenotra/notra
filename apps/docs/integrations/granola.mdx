The Granola integration gives the Notra agent read access to your [Granola](https://www.granola.ai/) meeting notes. Once connected, you can ask the agent in **Chat** or in [Slack](/integrations/slack) to pull context from recent meetings, summarize a call or draft content from a transcript.

## What the agent can do

The agent gets three tools per connected Granola workspace:

* **List notes** returns meeting notes with their AI summaries, attendees and timestamps, filtered by date range or folder.
* **Get a note** returns one note with its summary and metadata, and can include the full transcript.
* **List folders** returns your Granola folders so the agent can scope a search.

Access is read-only. Notra never creates, edits or deletes anything in Granola.

## Setup

<Steps>
  <Step title="Create a Granola API key">
    In the Granola app, open **Settings**, then **Connectors**, then **API keys**, and create a key. Keys start with `grn_`. Granola's own guide is at [docs.granola.ai](https://docs.granola.ai/help-center/sharing/integrations/granola-api).
  </Step>

  <Step title="Add the integration in Notra">
    In the dashboard sidebar, open **Integrations** and click **Connect** on the **Granola** card, or open the Granola page and click **Connect Granola**. Enter a **Display name** (for example "Team meeting notes") and paste the **API key**.
  </Step>

  <Step title="Save">
    Notra verifies the key against Granola before saving it. If Granola rejects the key, you get an error and Notra stores nothing. On success Notra encrypts the key and the toast reads "Granola connected".
  </Step>
</Steps>

## Managing the integration

The Granola page lists every connected workspace. From the card menu you can enable, disable or delete it. The agent cannot see a disabled integration. Deleting removes the encrypted key from Notra. If you no longer need the key, revoke it in Granola as well.

## Limits

- Granola is available to the agent only. It is not a source for the **Create Content** dialog, schedules or event triggers.
- The agent reads notes on request. Notra does not sync or store your Granola notes.
