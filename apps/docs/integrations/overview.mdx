Integrations live at **Integrations** in the dashboard sidebar (`app.usenotra.com/{org-slug}/integrations`). The page has four tabs: **All**, **Input**, **Output**, and **Extensions**. Below the tabs, a section called **From the integration store** lists MCP servers published by the Notra community.

## Input sources

Input sources feed data into Notra. GitHub and Linear power the Studio content pipeline (changelogs, blog posts, social posts). Slack gives you a chat channel with the Notra agent. Granola brings meeting notes into chat and content workflows. Google Search Console feeds GEO prompt suggestions.

  <Card title="GitHub" icon="github" href="/integrations/github">

  </Card>

  <Card title="Linear" icon="infinity" href="/integrations/linear" iconType="duotone">

## MCP servers

The **MCP Servers** card on the Integrations page opens `integrations/mcp`, where you connect external MCP servers so the Notra agent can use their tools and data.

* **Custom servers**: add any remote MCP server by name and URL (`https://` is prepended for you). Authentication is one of **None** (public server), **Headers** (an API key, bearer token, or custom headers), or **OAuth** (you are redirected to the server to approve access, and Notra stores an encrypted refresh token and renews access automatically).
* **Integration store**: servers published by the Notra community appear under **From the integration store**. Connecting one either needs no credentials, asks for your own headers, or starts an OAuth flow, depending on how the listing was published. Deep links of the form `app.usenotra.com/{org-slug}/integrations/{listing-slug}` open the connect dialog for a listing directly.
* Notra tests the connection while you add a server. Each connected server can be enabled, disabled, deleted, or have its tool list refreshed from its card.

<Note>
  This is the reverse direction from Notra's own MCP server, which lets AI tools like Claude or Cursor call Notra. For that, see [MCP Server](/devtools/mcp).
</Note>

## Content types from input sources

When you create content from GitHub or Linear activity, Notra can generate:

<Steps>
  <Step title="Changelog">
    Release notes grouped from merged pull requests, pushes, and releases.
  </Step>

  <Step title="Blog post">
    Long-form articles about a feature or release.
  </Step>

  <Step title="X post">
    Short updates announcing releases and features.
  </Step>

  <Step title="LinkedIn post">
    Professional updates about product and engineering progress.
  </Step>
</Steps>

Each repository you add through the GitHub App starts with changelog, blog post, and X post outputs enabled. LinkedIn posts and images are available when you create content or schedules.

## Getting started

<Steps>
  <Step title="Connect a source">
    Install the GitHub App, or connect Linear, and pick what Notra can read.
  </Step>

  <Step title="Generate content">
    Open **Content** and create a changelog, blog post, or social post from recent activity. Pick the repositories and Linear workspaces to include.
  </Step>

  <Step title="Automate">
    Use [schedules](/automation/scheduled) for recurring content, or [event triggers](/automation/event-based) that fire on GitHub webhooks.
  </Step>

  <Step title="Publish">
    Review drafts in the dashboard, publish social posts, or pull posts into Framer or your own site through the API.
  </Step>
</Steps>

## Permissions and security

<Note>
  * **Read access to your sources**: GitHub, Linear, Granola, and Google Search Console are read-only connections. Slack needs write access to post replies in threads.
  * **Selective access**: you choose which repositories the GitHub App can see, which Search Console property to analyze, and which Slack channels the agent may respond in.
  * **Encrypted credentials**: access tokens, API keys, webhook secrets, and MCP OAuth refresh tokens are encrypted at rest.
  * **Remove anytime**: every integration can be disabled or deleted from its page in the dashboard.
</Note>
