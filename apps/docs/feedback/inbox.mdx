Agents that use your product (coding agents, assistants, MCP clients) can report what went wrong or what they wish existed. The **Feedback** page in the dashboard collects those reports in one inbox.

## How agents send feedback

Each workspace has a public feedback URL that agents can POST to directly, or you can give them the MCP feedback tool that ships with `@usenotra/geo/feedback`. Publishing a `feedback.md` file on your site also earns a bonus point in [Agent Readiness](/geo/agent-readiness).

## Triage

Every report is a bug, a feature request or praise, and you move each one through **New**, **Triaged**, **Resolved** and **Archived**.
