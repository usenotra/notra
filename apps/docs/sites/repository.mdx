A site lives at the repository root or in a subfolder you choose when creating the site (useful for monorepos).

```text
notra.json              # name, logo, colors, navigation, redirects
blog/*.mdx              # blog posts, one file per post
changelog/*.mdx         # changelog entries, one file per release
snippets/*.mdx          # reusable content
snippets/*.jsx          # your own React components
public/                 # images and other static files
```

Files and folders starting with `_` are never published as pages. Everything else in `blog/` and `changelog/` becomes a page; the file path is the URL (`blog/2026/launch.mdx` → `/blog/2026/launch`).

## notra.json

```json notra.json
{
  "name": "Acme",
  "description": "Notes from the Acme team.",
  "logo": { "light": "/images/logo.svg", "dark": "/images/logo-dark.svg" },
  "favicon": "/images/favicon.svg",
  "navbar": {
    "links": [{ "label": "Product", "href": "https://acme.com" }],
    "cta": { "label": "Sign up", "href": "https://acme.com/signup" }
  },
  "footer": {
    "links": [{ "label": "Privacy", "href": "https://acme.com/privacy" }],
    "socials": { "x": "https://x.com/acme", "github": "https://github.com/acme" }
  },
  "blog": { "title": "Acme Blog", "description": "Product notes and launches." },
  "changelog": { "title": "Changelog", "description": "Everything we shipped." },
  "redirects": [{ "source": "/blog/old-post", "destination": "/blog/new-post" }]
}
```

The domain and the paths (`/blog`, `/changelog`) are configured in the dashboard, not in this file, so a commit can never move your site to a domain nobody verified.

## Design

Sites use the `notra` theme: the look of the Notra dashboard, with a light and a dark mode. You can change it to fit your brand, the same way Mintlify's appearance settings work.

```json notra.json
{
  "theme": "notra",
  "colors": { "primary": "#0D9373", "light": "#55D799", "dark": "#0D9373" },
  "appearance": { "default": "system", "strict": false },
  "fonts": { "family": "Inter", "heading": { "family": "Instrument Sans" } },
  "background": { "decoration": "grid", "color": { "light": "#F8FAFC", "dark": "#0F172A" } },
  "styling": { "codeblocks": "system" }
}
```

| Setting | What it does |
| --- | --- |
| `colors.primary` | Accent for links, eyebrows, active states and buttons. `light` is used in dark mode, `dark` for buttons. |
| `appearance` | `system`, `light` or `dark`. `strict: true` hides the dark mode toggle. |
| `fonts` | A Google Fonts family, or your own file with `source` (`/fonts/brand.woff2`) and `format`. `heading` and `body` override each part. |
| `background` | `decoration`: `none`, `grid`, `dots` or `gradient`, plus page colors per mode. |
| `styling.codeblocks` | `system`, `dark`, a [Shiki theme](https://shiki.style/themes) name, or `{ "light": …, "dark": … }`. |

### Custom CSS

Add a `style.css` (or any `.css` file in `styles/`) to the site root. It loads on every page after the theme, so it can override anything. Tailwind classes also work inside your MDX and components.

## Frontmatter

<CodeGroup>
```mdx blog/launch.mdx
---
title: "Introducing Acme Flow"
description: "A calmer way to ship product updates."
date: 2026-09-28
author: ["Jan", "Dominik"]
image: /images/launch.png
tags: [launch]
draft: false
---
```

```mdx changelog/2026-09-28.mdx
---
title: "Acme Flow is live"
date: 2026-09-28
version: v2.0.0
tags: [Feature]
---
```
</CodeGroup>

`draft: true` hides a post on the live site but shows it in previews. `noindex: true` keeps a published post out of search engines.

## Images

Put files in `public/` and reference them from the root: `![Logo](/images/logo.svg)`. Notra rewrites the path so it works under `/blog` and `/changelog`.
