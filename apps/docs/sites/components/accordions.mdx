An accordion hides details, like an FAQ answer, under a title that readers click to open.

```mdx
<AccordionGroup>
  <Accordion title="Does Acme Flow work offline?" defaultOpen>
    Yes. Changes sync when you're back online.
  </Accordion>
  <Accordion title="Can I use my own domain?">
    Yes, a subdomain or a path on your website.
  </Accordion>
</AccordionGroup>
```

Accordions work without JavaScript, and search engines read their content even when they're closed. `AccordionGroup` draws a line above the first accordion so a list of them looks like one block.

## Props

### Accordion

<ResponseField name="title" type="string" required>
  The question or label readers click.
</ResponseField>

<ResponseField name="defaultOpen" type="boolean" default="false">
  Open the accordion when the page loads.
</ResponseField>

`AccordionGroup` takes no props.

## Styling

Accordions carry the class `accordion` and groups carry `accordion-group`.
