Tabs show alternatives, like package managers or platforms, in one place, so readers pick the one that applies to them.

````mdx
<Tabs>
  <Tab title="npm">
    ```bash
    npm install acme
    ```
  </Tab>
  <Tab title="bun">
    ```bash
    bun add acme
    ```
  </Tab>
</Tabs>
````

The first tab is open when the page loads, and readers switch with a click or with the arrow keys. Without JavaScript, every tab shows one below the other under its title.

## Props

### Tab

<ResponseField name="title" type="string" required>
  The tab's label.
</ResponseField>

`Tabs` takes no props.

## Styling

Tab groups carry the class `tabs` and each panel carries `tab`.
