`Steps` numbers the steps of a setup or a tutorial, with a title next to each number.

```mdx
<Steps>
  <Step title="Connect GitHub">
    Install the GitHub App on the repository.
  </Step>
  <Step title="Add a post">
    Push `blog/hello-world.mdx`.
  </Step>
  <Step title="Go live">
    Every push to the production branch deploys the site.
  </Step>
</Steps>
```

Notra numbers the steps in order, starting at 1.

## Props

### Step

<ResponseField name="title" type="string">
  The step's headline, next to its number.
</ResponseField>

`Steps` takes no props.

## Styling

The list carries the class `steps` and each item carries `step`.
