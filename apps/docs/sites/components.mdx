## Built-in components

Use these in any MDX file without importing them: `Note`, `Tip`, `Info`, `Warning`, `Check`, `Danger`, `Callout`, `Card`, `CardGroup`, `Columns`, `Tabs`, `Tab`, `Steps`, `Step`, `Accordion`, `AccordionGroup`, `CodeGroup`, `Frame`, `Badge`, `Update`, `Video`, `YouTube`.

```mdx
<Tip>You need Node 22 or newer.</Tip>

<Tabs>
  <Tab title="npm">npm install acme</Tab>
  <Tab title="bun">bun add acme</Tab>
</Tabs>
```

## Your own components

Declare a component inline or put it in `snippets/` and import it. Components are interactive in the browser.

<CodeGroup>
```mdx Inline
export const Counter = () => {
  const [count, setCount] = useState(0);
  return <button onClick={() => setCount(count + 1)}>{count}</button>;
};

<Counter />
```

```jsx snippets/counter.jsx
export const Counter = ({ start = 0 }) => {
  const [count, setCount] = useState(start);
  return <button onClick={() => setCount(count + 1)}>{count}</button>;
};
```

```mdx Using a snippet
import { Counter } from "/snippets/counter.jsx";

<Counter start={3} />
```
</CodeGroup>

Tailwind classes work in your components.

### Rules

- React hooks (`useState`, `useEffect`, `useRef`, `useMemo`, …) are available without importing them.
- Use named exports. Default exports are not supported.
- No npm packages, JSON imports or dynamic `import()`. Use browser APIs instead.
- Component snippets (`.jsx`) cannot import other snippets. Import everything in the MDX file.
- Inline components cannot use values imported in the same MDX file; move them into a snippet.
- Node.js APIs such as `process` or `require` are not available.

Components render once during the build and then run in the browser, so do not read `window` or `document` while rendering. Use `useEffect`, or add `client:only="react"` to render a component only in the browser.

## Reusable content

MDX snippets can be imported anywhere, can import other MDX snippets, can export values, and take props:

```mdx snippets/install.mdx
Install **{packageName}** with your package manager.
```

```mdx
import Install from "/snippets/install.mdx";

<Install packageName="acme-flow" />
```

## Security

Builds run in a sandbox without network access or credentials. Your components are served from your domain, so anyone who can commit to the repository can run JavaScript on `acme.com/blog`. Only give write access to people you trust with your website.
