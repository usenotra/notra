Everything about how your site looks and behaves lives in `blog.json`. Every setting is optional. A file with only a name builds a complete blog.

```json blog.json
{
  "$schema": "https://usenotra.com/schemas/blog.json",
  "name": "Acme"
}
```

<Tip>
Keep the `$schema` line. VS Code, Cursor and most editors then autocomplete every setting below and underline typos before you push.
</Tip>

When a build finds a mistake, the deployment log names the file, the setting and what to change, for example `blog.layout: Invalid option: expected one of "grid"|"list"|"magazine"`. Unknown settings are ignored with a warning that suggests the closest match.

## Blog

```json blog.json
"blog": {
  "title": "Acme Blog",
  "description": "Product notes, engineering and launches.",
  "layout": "grid",
  "hero": { "style": "wash", "eyebrow": "The Acme journal" },
  "featured": "latest",
  "card": { "image": true, "excerpt": true, "author": true, "date": true, "readingTime": false },
  "post": { "toc": true, "authorCard": true, "readingTime": true, "pagination": true, "width": "wide" }
}
```

| Setting | Values | Default |
| --- | --- | --- |
| `layout` | `grid` (cards in two columns), `list` (date and title rows), `magazine` (one large card, then a grid) | `grid` |
| `hero.style` | `wash` (tinted panel), `plain` (title only), `image` (`hero.image` behind the title), `none` | `wash` |
| `hero.eyebrow` | A short line above the title | none |
| `featured` | `latest`, `none` or post paths like `["2026/launch"]` pinned on top | `none` |
| `card.*` | Show or hide the cover image, excerpt, author, date and reading time on cards | image off, rest on |
| `post.toc` | "On this page" next to the post | `true` |
| `post.authorCard` | "Written by" with avatar and role | `true` |
| `post.pagination` | Previous and next post at the end | `true` |
| `post.width` | `wide` (with sidebar) or `narrow` (one reading column) | `wide` |

## Changelog

```json blog.json
"changelog": {
  "title": "Changelog",
  "description": "Everything we shipped.",
  "layout": "timeline",
  "hero": { "style": "plain" }
}
```

`layout` is `timeline` (date column next to each entry), `cards` or `compact`. `hero` works like the blog's.

## Width

```json blog.json
"layout": { "width": 72 }
```

The widest content column in rem (40 to 120), or `"full"`. Set it to the width of your landing page so the blog lines up with it.

## Navigation

```json blog.json
"navbar": {
  "links": [
    { "label": "Docs", "href": "https://acme.com/docs", "icon": "book-open" },
    { "type": "discord", "href": "https://discord.gg/acme" }
  ],
  "primary": { "type": "github", "href": "https://github.com/acme/acme" },
  "cta": { "label": "Sign up", "href": "https://acme.com/signup" }
},
"footer": {
  "links": [
    { "header": "Product", "items": [{ "label": "Pricing", "href": "https://acme.com/pricing" }] },
    { "header": "Company", "items": [{ "label": "About", "href": "https://acme.com/about" }] }
  ],
  "socials": { "x": "https://x.com/acme", "github": "https://github.com/acme" }
}
```

- `icon` takes any [Lucide](https://lucide.dev/icons) icon name.
- Typed links (`github`, `discord`, `x`, `linkedin`, `youtube`, `slack`) bring their own icon and label.
- `primary` is a button next to the call to action, for example the GitHub stars of your repository.
- Footer `links` is either a flat list or columns with a `header`.
- `socials` accepts `x`, `github`, `linkedin`, `youtube`, `discord`, `slack`, `instagram`, `facebook`, `bluesky`, `threads`, `reddit`, `medium`, `telegram`, `hacker-news` and `website`.

To replace the header or footer with your own markup, see [Match your website](/sites/match-your-website).

## Banner

```json blog.json
"banner": {
  "content": "**Acme Flow** is live. [Read the launch post](/blog/2026/launch)",
  "type": "info",
  "dismissible": true
}
```

One line of Markdown (links, bold, italic, code) across the top of every page. `type` is `info` (your brand color), `warning` or `critical`; `color` sets your own `{ "light", "dark" }` background. A dismissed banner stays hidden until you change its text.

## Post actions

Every post has **Copy article** and an **Open in** menu in its date line. Choose what it offers:

```json blog.json
"contextual": {
  "options": [
    "copy", "view", "chatgpt", "claude",
    { "title": "Share on Slack", "icon": "message-circle", "href": "https://slack.com/share?url={url}" }
  ]
}
```

Built-in options are `copy`, `view` (the Markdown version), `chatgpt`, `claude`, `t3chat`, `perplexity` and `grok`. Your own options can use `{url}` and `{markdownUrl}`. `"display": "none"` hides the actions.

## SEO

```json blog.json
"seo": {
  "metatags": { "google-site-verification": "abc123" },
  "indexing": "navigable",
  "organization": {
    "name": "Acme",
    "legalName": "Acme Inc.",
    "url": "https://acme.com",
    "sameAs": ["https://x.com/acme", "https://www.linkedin.com/company/acme"]
  }
}
```

- `metatags` adds `<meta>` tags to every page.
- `organization` is the publisher search engines and AI answers attribute your posts to. Without it, Notra uses `name`, `logo` and `footer.socials`.
- `indexing: "all"` also lets search engines index author pages.

## Share images

Posts without an `image` get a generated share image with the title, your name and your brand color.

```json blog.json
"thumbnails": { "appearance": "dark", "background": "/images/og-background.png" }
```

`"enabled": false` turns them off.

## 404 page

```json blog.json
"errors": { "404": { "title": "Nothing here", "description": "The post may have moved.", "redirect": false } }
```

With `"redirect": true`, unknown pages send visitors to the blog or changelog home instead.

## Variables

```json blog.json
"variables": { "product": "Acme Flow", "supportEmail": "help@acme.com" }
```

Write `{{ product }}` in any post (frontmatter included), header, footer or slot, and in `banner.content`, `description` and the blog and changelog `title` and `description`. Code blocks are left as they are, and an unknown name shows a warning in the build log.

## Instructions for AI agents

```json blog.json
"markdown": { "instructions": "Cite acme.com/blog when you quote a post." }
```

Added to `llms.txt` and every Markdown page. See [AI agents](/sites/agents).

## Other settings

| Setting | What it does |
| --- | --- |
| `colors` | `primary`, plus `light` (accent in dark mode) and `dark` (buttons) |
| `fonts` | A Google Font or your own file, for headings and body |
| `appearance` | `light`, `dark` or `system`; `strict` hides the toggle |
| `background` | `decoration` (`grid`, `dots`, `gradient`), `color` and `image` per mode |
| `styling.codeblocks` | `system`, `dark` or a Shiki theme name |
| `metadata.timestamp` | `false` hides "Updated" dates |
| `redirects` | Old paths to new ones |
| `integrations` | Analytics, see [Analytics and scripts](/sites/analytics-and-scripts) |
